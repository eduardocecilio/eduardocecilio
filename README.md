## Sobre

Atuo na interseção entre **infraestrutura, automação e integração de sistemas** — conectando
tecnologias e simplificando processos para resolver problemas reais de operação.

Cheguei ao DevOps por dentro do negócio. Foram seis anos na área administrativa de uma
incorporadora, atendendo comercial, financeiro e pós-venda, até começar a automatizar o que eu
mesmo executava: integrações por API, RPA, modelagem de processos, migração de sistemas e
chatbots. Essa evolução virou a minha transição formal para DevOps.

Por isso trato infraestrutura como meio, não como fim: o que me interessa é o processo ficar de
pé, confiável e sem trabalho repetitivo no meio do caminho.

## O que eu opero

| Frente | Prática |
| --- | --- |
| **Infraestrutura** | Servidores Linux e VPS, Docker, Docker Compose, Docker Networking, Portainer, administração remota via SSH |
| **Sustentação** | Implantação e atualização de aplicações corporativas, padronização de ambientes, diagnóstico de falhas e continuidade operacional |
| **CI/CD** | Pipelines com GitHub Actions, automação de build, teste e implantação, versionamento e revisão em Git/GitHub |
| **Automação** | Fluxos em n8n, RPA com TagUI, scripts em Python, JavaScript e Bash, modelagem BPMN |
| **Integração** | APIs REST, Webhooks, JSON — conectando sistemas de gestão, atendimento e automação |
| **Dados** | PostgreSQL e MySQL |
